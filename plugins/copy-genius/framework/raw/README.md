# Raw — Parking Area

> Drop here anything you want to process later: PDFs, screenshots, URLs, copy snippets, transcripts, articles, notes. No structure required. Files in this folder are waiting to be analyzed and routed somewhere useful.

## How to use

1. **Drop a file**: paste a PDF, save a screenshot, copy in a URL, paste raw text. Use any filename you want.
2. **Ask Copy Genius**: say "process the latest item in /raw/" or "what's in /raw/?" and the orchestrator will read what's there.
3. **Copy Genius routes it**:
   - Looks like a swipe (ad, sales letter, landing page, hook)? Suggests ingesting it into the swipe library via [swipe-ingestion](../skills/swipe-ingestion.md).
   - Looks like a note / observation / strategy lesson? Suggests adding to [strategy-notebook.md](../strategy-notebook.md).
   - Looks brand-specific (avatar interview, testimonial, brand asset)? Suggests adding to the relevant `brands/<brand>/` folder.
4. **You confirm**: Copy Genius never moves things without your OK.
5. **After processing**: the raw file stays here as archive, or you delete it manually. Copy Genius will not auto-delete.

## What this folder is NOT

- Not a place to store source materials for the wiki's core knowledge (those are already baked into `core/`)
- Not a backup folder
- Not version-controlled inbox (no metadata, no sorting)

Just a parking spot for things you found and haven't decided what to do with yet.
