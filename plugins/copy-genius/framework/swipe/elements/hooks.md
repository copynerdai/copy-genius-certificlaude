# Hook Library

> **Read IN FULL before writing any opening** (ad, email subject+open, VSL cold open, LP first line, advertorial lead-in). This library is deliberately short-format so the full repertoire fits in one read — the writer never starts from zero.
>
> **Compiled library** — populated by [swipe-ingestion](../../skills/swipe-ingestion.md); the source of truth is each piece entry (`from:` slug). Do not edit rows here by hand; fix the entry and recompile.
>
> **Rules of use:**
> 1. **Templates are emotion-agnostic.** `emotion-as-used` records how the original instantiated it — re-instantiate with the brief's emotional anchor. A fear hook structure can carry hope; a curiosity structure can carry anger.
> 2. **Verbatim stays in its original language.** Use the TEMPLATE line to generate natively in the target language. Structure crosses languages, phrasing never.
> 3. When proposing variants, cite the template's `from:` slug in the variant metadata so provenance survives.

**Scope**: every opening device in the hook-specialist taxonomy — ad openers, VSL cold opens, LP first lines, advertorial lead-ins, AND **email subject lines** (they are hooks in this system). The `usage:` tag tells them apart.

## Entry format

```
◦ "<verbatim, original language>"
  TEMPLATE: [component] + [component] + ...
  <hook-type> · usage: <ad-open | subject-line | vsl-open | lp-first-line | advertorial-lead-in | universal> · emotion-as-used: <X> · awareness: <Y> · lang: <Z> · from: <slug>
```

**Admission test — position ≠ function.** The first line of a page is NOT automatically a hook. To enter this library a line must have **standalone stopping power on a cold reader**: open loop, curiosity gap, or emotional jolt that works on someone who does NOT know the product. Offer banners, scarcity lines, and deal announcements opening product/most-aware pages are PRE-HEADLINES → [headlines library](headlines.md), not hooks.
