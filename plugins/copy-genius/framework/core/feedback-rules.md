# FEEDBACK RULES — Global

> User-accumulated rules from feedback that apply to **ALL brands**. Read by the orchestrator at routing time and by every writing specialist at Fase 1 and Fase 4d of [writing-principles](core/writing/writing-principles.md).
>
> **This file is YOURS.** It starts empty — you grow it as you work, by telling Copy Genius "salva globalmente" when you want a preference to apply to every brand. It is a protected user-data file: framework updates never overwrite it.
>
> **Precedence: brand-copy-rules > this file > writing-principles defaults.** Brand-specific rules (`brands/<brand>/brand-copy-rules.md`) override these in case of conflict; both override the defaults in writing-principles.
>
> Copy Genius NEVER adds rules autonomously. Only the user can authorize a new rule via commands like:
> - "salva globalmente" / "save globally"
> - "ricorda questa regola per tutti i brand"
> - "salva questa regola" + scope answered as "global"
>
> When Copy Genius is asked to save a rule, it:
> 1. Asks for the scope (brand or global) if not specified
> 2. Checks for similar existing rules → proposes UPDATE instead of duplicating
> 3. Formulates the rule with category + do/don't + why + example, AND fills the Severity / Phase / Scope fields of the index (see Index legend)
> 4. Shows it for approval → on confirm, appends here + updates the index
> 5. **Double registration for phrase/construction bans** (per CLAUDE.md §9): if the rule bans a specific phrase or construction, ALSO append a row to your protected [banned-phrases-user](core/writing/banned-phrases-user.md) file — that file is read mechanically by the QA scan (Fase 4c) alongside the framework banned table. This file keeps the full rationale and example; that row keeps the mechanical match. Both are protected user data, so they survive framework updates together.
>
> **When to save GLOBAL vs BRAND**: a rule is global if it concerns the writer's universal style preference (e.g., "always line break after every period", "never use AI cliché X"). It's brand-specific if it touches the brand's voice, vocabulary, claims, or operational details that don't transfer.
