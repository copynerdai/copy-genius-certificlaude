# Bullet Library

> **Read IN FULL before writing bullet/fascination blocks.** Short-format by design.
>
> **Compiled library** — populated by [swipe-ingestion](../../skills/swipe-ingestion.md); source of truth = the piece entries (`from:` slug). Don't edit rows by hand.
>
> **Rules of use:**
> 1. **Templates are emotion-agnostic** — `emotion-as-used` is swappable with the brief's anchor.
> 2. **Verbatim stays in its original language**; generate natively in the target language from the TEMPLATE line. Structure crosses languages, phrasing never. Tier 1 style bans (writing-principles B.1–B.3) apply to all delivered copy regardless of what these examples model.
> 3. Complements the formula catalog in [bullet-point-specialist](../../section-specialists/bullet-point-specialist.md) — this file holds curated, proven instances.

## Entry format

```
◦ "<verbatim, original language>"
  TEMPLATE: [component] + [component] + ...
  <bullet-type> · emotion-as-used: <X> · lang: <Z> · from: <slug>
```
