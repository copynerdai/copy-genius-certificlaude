# Headline Library

> **Read IN FULL before writing any headline block** (pre-headline + H1 + sub for LP / sales page / ad / blog / VSL thumbnail). Short-format by design: the full repertoire fits in one read.
>
> **Compiled library** — populated by [swipe-ingestion](../../skills/swipe-ingestion.md); source of truth = the piece entries (`from:` slug). Don't edit rows by hand.
>
> **Rules of use:**
> 1. **Templates are emotion-agnostic** — `emotion-as-used` is the original instantiation, swappable with the brief's anchor.
> 2. **Verbatim stays in its original language**; generate natively in the target language from the TEMPLATE line. Structure crosses languages, phrasing never.
> 3. These complement (not replace) the Formula Library in [headline-specialist](../../section-specialists/headline-specialist.md) — this file holds YOUR curated, proven instances; that one holds the generic pattern catalog.

## Entry format

```
◦ "<verbatim, original language>"
  TEMPLATE: [component] + [component] + ...
  <pattern> · emotion-as-used: <X> · awareness: <Y> · lang: <Z> · from: <slug>
```
